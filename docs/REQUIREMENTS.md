# 需求说明 — 极速开发工具箱（Easy Dev Tools）

> 本文档记录产品定位、功能范围与迭代约束，作为持续迭代的验收依据。署名：hxd。

## 1. 产品定位

- 面向开发者的在线工具集合，生产地址 tools.morijiu.cn，测试地址 tools.test.morijiu.cn。
- 核心卖点：**纯前端、数据不上传服务器**。所有工具均在浏览器本地运行，不引入后端服务、不采集用户输入内容。
- 体验目标：打开即用、无需注册、操作路径短、结果可一键复制。

## 3. 产品原则

1. **本地优先**：新功能一律前端实现；确需网络时只加载静态资源，不发送用户数据。
2. **紧凑现代**：界面紧凑、信息密度合理，避免大面积留白与过大的按钮；交互反馈即时。
3. **不硬造功能**：优先补齐高频小能力（搜索、收藏、复制、校验、错误提示），不堆砌低频工具。
4. **一致性**：工具间统一输入/输出/复制/清空/交换等交互模式；页脚版权统一为「© <年份> morijiu.cn」。
5. **版本可见**：页脚显示版本号；生产为裸版本号，测试环境加 `_test` 后缀，本地开发加 `_dev` 后缀。

## 4. 迭代路线

- R1 地基：需求/设计文档入仓、版本徽标、测试环境落地与构建验证。
- R2 首页与发现：工具搜索（关键词/别名）、分类快速导航、统计与空状态。
- R3 常用能力：收藏与最近使用（localStorage）、统一复制/清空/交换交互。
- R4 UI v2：紧凑视觉、暗色模式、移动端布局优化。
- R5 键盘与友好性：命令面板/快捷键、无障碍、页脚版权核查。
- R6 新工具扩充：按实用度逐个增加纯前端工具（如 JWT 解码、Cron 解析、正则测试、Diff 对比、进制转换）。
- R7 存量增强：逐个工具补示例、校验、错误提示与批量处理，并做截图自审。

## 5. 非目标

- 不做账号体系、不做服务端存储、不做付费功能。
- 不在公开仓库记录任何内部基础设施细节（服务器地址、部署凭据等）。
